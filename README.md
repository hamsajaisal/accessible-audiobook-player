# Accessible Audiobook & Music Player

An open-source, accessibility-first desktop audio player designed specifically for **Windows** and **Linux**.

Unlike generic media players, this application is designed around long-form listening (audiobooks), study (creating clips/highlights), and keyboard-friendly, screen-reader-friendly operations.

## Key Features

- **Accessibility-First**: Works out-of-the-box with **NVDA**, **JAWS**, **Narrator** (on Windows) and **Orca** (on Linux).
- **Audiobook & Music Playback**: Plays MP3, M4A, WAV, FLAC, OGG, and AAC files. Easily open folders of files or individual songs.
- **Intelligent Resume**: Remembers the exact second you paused in each audiobook folder, so you can resume listening instantly.
- **Bookmarks & Highlights (Clips)**: Save important timestamps, create time-range clips (e.g. 2:10 to 3:45), and attach notes.
- **Revision Mode**: A dedicated study mode that plays back only your saved clips/highlights in sequence (ideal for revision and learning).
- **Pitch-Preserved Speed**: Play audio at faster or slower speeds (0.5x to 3.0x) without distortion or pitch shifting (voices won't sound high-pitched).
- **Sound Booster**: Boost audio volume up to 200% using built-in software gain controls.
- **No Complex Setup**: Automatically compiled and packaged on GitHub Actions, requiring no coding tools on your computer.

## Keyboard Shortcuts (Quick Reference)

These shortcuts work globally across the app when you are not typing in a text field:

- **Spacebar**: Play or Pause playback.
- **Left Arrow**: Seek backward 10 seconds.
- **Right Arrow**: Seek forward 10 seconds.
- **Up Arrow**: Increase volume by 5%.
- **Down Arrow**: Decrease volume by 5%.
- **Page Up**: Skip to the previous audio track in the folder.
- **Page Down**: Skip to the next audio track in the folder.
- **Tab / Shift+Tab**: Navigate through buttons and controls with high-visibility focus indicators.

## Installation & Download

We build the player in the cloud! To download the latest version:
1. Open the **Releases** section on our GitHub repository.
2. Download the `.exe` installer for Windows or the `.AppImage` / `.deb` file for Linux.
3. Install and run!
